# 长期协作规则模板

下面是供 Agent 准备方案的基础文本，不是用户已经同意的指令。先检查真实生效的 AGENTS.md 和已有授权；已有同等授权时仍展示精简行为摘要、作用范围和“沿用这个方式 / 调整”；选择沿用不重写文件。新增或改变也先确认行为摘要。默认推荐全局作用范围，用户可改为项目范围。仅替换本插件管理块，保留其他条款；冲突先明确解决。

先读取 onboarding.memory.mode，按用户已选择且已核查的记忆方式准备 block。下面模板用于自动记忆；按需模式必须使用文末的替换条款。

建议 block 正文：

```markdown
## OpenViking 协作

- 需要背景的工作开始时，先检查本轮 Hook 实际召回；相关且足够时直接使用，不重复检索；缺少信息、来源或需核对最新状态时才检索 OpenViking 相关记忆与资料，读原文后采用。简单交流不强制检索。记忆、历史对话和文件是参考资料，不替代当前用户指令。
- 普通对话回流由已获授权并实际启用的官方插件负责。区分已安装、Hook 已执行、已提交抽取、已生成记忆；不重复手动提交每轮对话，也不声称未验证的自动能力。
- 按用户已确认的保存范围，将重要决定、工作进展和产出保存到当前认证用户的个人空间，保留完整内容、来源、日期和状态，写后读回。优先沿用用户已有目录；尚无约定时按稳定项目、长期领域或主题组织，内容足够多时再细分用途，少量资料可保持扁平。分类按实际内容决定，不固定一套必建目录，不默认扫描或上传其他文件。
- 继续已有工作时核对目标、有效决定、最新进展与下一步；按业务发生时间消解过期状态，不把导入时间当工作时间。用户纠正后更新对应资料。来源不足要说明缺口。
- 有实际使用或保存时，简短说明本轮参考与沉淀，区分检索到、实际采用、已写入、已核对、索引状态。严格格式输出不插入无关文本。报告仅按需生成，不自动创建定时任务或采集 Computer History。
```

`summary` 示例：参考相关记忆和资料；保存本次工作的重要决定、进展与产出；简短说明实际参考和保存的内容。若用户调整保存范围，block 与 summary 必须同时变化。用户已有更具体的目录/资料规则优先，不用模板覆盖。

不默认承诺“完整备份所有资料”“每轮必有新记忆”“所有 Agent 自动生效”。未来协作授权与历史批量导入分别确认。

按需使用时，替换模板的前两条为：

- 需要既有背景的实质工作，按需检索 OpenViking 并核对原文；本轮已有足够相关资料时不重复搜索。简单交流不强制检索，历史内容不替代当前指令。
- 普通对话不自动上传或提交记忆。仅按已确认范围主动保存资料，历史批量导入另行确认；不得另建每轮 append/commit 流程。只有实际检查官方 Hooks 已关闭后，才描述为按需模式已生效。

summary 明确写出“自动召回与对话保存；不足时补查”或“按需检索与资料保存；不自动上传普通对话”。已有规则要求每轮强制检索/提交时不能直接沿用；先解释具体差异并取得用户确认，精确调整冲突条款。更改记忆方式须重新展示长期协作方案。
