# OpenViking Codex App v0.2.7

本次为文档更新，将已有的多用户绑定与切换流程补充到项目 README，未改变插件运行逻辑。

## 更新

- 增加新增用户绑定的完整步骤：选择安装方式、验证 Key、进入新任务、完成该用户的接入。
- 提供可复制的查看绑定、按 User ID 或服务展示名切换用户的指令。
- 说明同一 User ID 的多连接选择、首次隔离配置与重启、已保存绑定的恢复方式。
- 明确切换影响设备默认连接，已有任务保留原连接；历史不自动迁移，普通任务不会自动打开绑定卡片。
- 澄清多用户连接与个人版工作台的支持范围，不承诺企业套餐自动识别或团队管理能力。

## 使用与升级

直接阅读 [README 中的绑定与切换用户流程](https://github.com/zhangxiaoyan1081/openviking-developer-codex-app#绑定与切换-openviking-用户)。已安装 0.2.6 的用户无需为阅读这次文档更新重新安装。

需要更新分发包时，解压附件 `openviking-codex-app-v0.2.7.zip`，在目录执行：

```bash
python3 install.py --companion-only
```

保留已有用户配置与官方记忆插件。更新后新开任务加载新版，宿主仍复用旧进程时重启 Codex。
