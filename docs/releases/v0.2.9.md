# OpenViking Codex App v0.2.9

2026-10-09 · 工作台用户切换与新用户接入入口。

## 更新

- 工作台顶部新增用户菜单，展示服务展示名、User ID、Account 和可用的库 ID；同名绑定可区分。
- 点击已有绑定后先验证再切换，目录、进展和报告刷新为目标用户；验证失败或页面状态过期时保留原连接。
- 「新增用户 → 在新对话中接入」复用对话 onboarding：保存新绑定、检查 Hooks、确认记忆与长期协作方式、选择历史导入。已保存但未完成的绑定继续原流程，不重复索取 Key。
- 对话新增或切换绑定后，返回工作台或刷新即可读取同一份绑定列表。
- 右侧本地网页及不支持新对话扩展的宿主提供可复制的接入指令。
- 工作台独立读取已验证的当前身份；旧对话的官方 MCP 与 Hook 隔离检查不变。后台扫描通过标准输入取得固定身份，凭据不进入命令行、页面或结果。

## 升级

在解压后的发行目录执行：

```bash
python3 install.py --companion-only
```

重新加载桌面客户端后打开 OpenViking 工作台，点击顶部用户菜单。已有官方记忆插件默认复用，不随 App 升级重装。

切换会改变设备默认连接：工作台立即读取新用户，新对话使用目标用户，已运行对话保留原连接。首次配置连接隔离组件时按提示重启并审核 Hooks；隔离未就绪时不会强行切换。

## 验收与边界

本地验证包括 108 项 Python 测试、5 项 MCP 测试及 5 组浏览器回归。新增覆盖切换验证失败、过期点击、连接隔离、只读请求固定身份、旧结果丢弃、聊天绑定刷新、同名连接、新对话消息和复制兜底。HTTP 切换经过本机来源与 CSRF 检查。测试使用隔离配置和虚构数据，不切换用户真实连接。

当前 Codex 客户端代码支持 `ui/message` 的 `openai/message.target=new` 扩展，页面会检测能力。模拟宿主已验证点击和消息参数；真实 Codex 主窗口自动化受限，原生左栏点击到新接入对话的链路尚未端到端验收，不代表所有宿主版本支持。未验证其他操作系统或干净设备安装。
