# OpenViking Codex App v0.2.8

2026-10-09 · 本地侧栏入口原型，未提交官方公共插件目录。

## 更新

- 新增 OpenViking 全局侧栏入口声明，使用独立 MCP App 工作台资源和原品牌图标。
- 无需先发起对话或等待工具结果通知，页面初始化后主动读取工作台。
- 默认展示目录，可浏览 L0/L1、文件、Session 工作进展和已生成报告。
- 工作台使用独立只读状态接口，不推进 onboarding、不确认连接或协作规则、不触发历史导入。
- 入口仅对 App/宿主可见，普通任务不会因此多出工作台卡片。保留原右侧工作台打开方式。

## 升级与试用

在解压后的发行目录执行：

```bash
python3 install.py --companion-only
```

重启桌面客户端以重新发现 MCP 入口。支持此扩展的宿主可在左侧显示 OpenViking；点击后进入工作台。若未显示，仍可发送“打开我的 OpenViking 工作台”使用右侧入口。

## 验收与边界

本地已通过 101 项 Python 测试、5 项 MCP 测试及 5 组浏览器回归。真实安装后的 v0.2.8 已通过最小 PATH 启动检查；新启动的 Codex app-server 已发现 33 个工具、全局入口声明，并成功读取独立工作台 HTML。

上述回归覆盖只读状态、入口元数据、资源、无前置结果启动、未连接/刷新、目录预览、进展概览、报告、重开和失败重试。GitHub Actions 通过全部检查后生成不可覆盖的版本附件和 SHA-256。
