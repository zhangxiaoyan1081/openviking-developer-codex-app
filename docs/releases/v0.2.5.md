# OpenViking Codex App v0.2.5

本版修复 Codex 桌面更新后程序路径变化导致的用户绑定启用失败，并将此前本机验证的多用户绑定与切换实现纳入分发。

## 更新

- 运行时发现有效的 Codex 程序，兼容旧路径、新桌面布局及最小 PATH。安装器和切换器不再自动固定安装当天的程序路径。
- 已保存的绑定在本机检查失败后可继续启用，无需重新提交 API Key；保留连接隔离检查，并提供明确的本机错误提示。
- 支持在对话中新增用户绑定、查看绑定和按 User ID/服务展示名切换；新任务使用目标连接，旧任务保持原连接。实际身份从服务端校验，库 ID 未返回时不阻塞绑定。
- 更新 App 同时刷新已安装切换器的路径发现代码，保留当前用户、凭据及官方 Hooks。

## 安装与升级

下载并解压附件 `openviking-codex-app-v0.2.5.zip`，在解压目录执行：

```bash
python3 install.py --companion-only
```

需要 Python 3.10+、Node.js 22+、Git 和 Codex。分发包已有构建资源，不需要运行 npm install。

安装后新开 Codex 任务，发送“使用 openviking-codex-app 接入 OpenViking”。已有待完成绑定则继续原流程，不重复提交已保存的 Key。宿主仍复用旧 MCP 进程时，重启 Codex。

多用户隔离组件为可选能力；首次使用且尚未安装时，由 Codex 核对后执行 `python3 scripts/install-switcher.py`。首次隔离升级需要重启 Codex，Hook 命令变化时由用户审核信任。App 更新不会代替用户批准 Hooks，也不会自动迁移历史。

- 100 项 Python 测试、4 项 MCP 集成测试和 4 组模拟宿主浏览器回归通过。
- macOS 上已验证新版 Codex CLI `0.162.0-alpha.2`：旧路径与最小 PATH 下的程序发现、插件/Hook 查询、切换前隔离检查通过。
- 已从本机实际注册入口验证 0.2.5 的工具、卡片数据及 HTML 资源。安装前后当前连接、绑定与官方插件配置保持一致。
- 本次未重新执行真实用户切换，未完成其他操作系统及干净设备的完整安装验收；模拟浏览器不等于 Codex 原生 UI 完整验收。

ZIP 包含安装器、插件、已构建资源、源码与文档；不包含个人配置、API Key、node_modules 或历史会话。可使用附带的 `SHA256SUMS` 核对下载文件。
